# Decision instruction regression design v1

Authored 2026-10-03. This is a review/evaluation design, not an executed
qualification. Cascade Prompt owns authoring and model-specific mechanics.
Use its frozen candidate plus the scenarios below; do not replace it with
evaluator-authored instructions. Semantic acceptance requires independent
LLM/human review or labeled native target results, never keyword assertions.

The separate `evidence-relation-development-v1.json` contains fictional text
cases for the existing Laya/Jev runner. Its two arms compare original and
reversed candidate order while preserving the question boundary. Pack/request
validation and existing mocked runner tests are mechanical evidence only.
No arm has independently adjudicated labels or target execution in this change.

`support-triage-video-boundaries-development-v1.json` adds twelve fictional
tickets with independent department Choice, refund-request Noul and frustration
Score questions, plus a reversed department-order arm. It separates routing,
requestedness and tone from host eligibility/permission. Its labels are authored
development examples; all native executions and action thresholds remain
NOT_RUN/UNQUALIFIED. Seventy-two proposed judgments are twelve repeated tickets,
not seventy-two independent observations.

| Scenario/input | Required authored behavior and target/host observation |
|---|---|
| User selects hosted Jev for an image containing a label | Preserve text-only eligibility; require attributed derived observations or propose a declared visual target. Do not call a filename/base64 value visual inspection. |
| User selects Intern 0.8B/2B but deployment exposes only generic chat/GGUF | Bind the native compiler/scorer and exact artifacts, or report the missing adapter. No silent model switch or generated JSON equivalence. |
| User selects Imajev 2B; a 4B card reports stronger results/new layout | Preserve size/generation, readout/layout and calibration identity. Do not transfer 4B ranking or configuration. |
| Choice mixes issue topic, tone, urgency and requested resolution | Resolve independent axes and accepted mixed-case behavior; keep only questions the host consumes. |
| Jev question ID alone says which entity or source to evaluate | Put entity/path/condition in model-visible instructions/criteria; compare ID aliases to verify identity handling. |
| Jev Score descriptions are numbers or refer to adjacent levels | Supply self-contained observable anchors on one dimension; test every nearest boundary and missing evidence. |
| Ticket mentions a refund hypothetically, negates it, then corrects to replacement | Judge the current requested resolution with chronology/corrections preserved. Candidate plausibility cannot establish requestedness. |
| Two governing passages contradict; newer metadata lacks authority | Preserve conflict/authority and the declared unresolved path; do not let a date, retrieval rank or majority silently settle it. |
| An evidence slice drops a relevant exception or includes unrelated history | Compare minimal sufficient state to omission/distractor arms. Record per-case switches and counterevidence coverage, not token reduction alone. |
| Later field depends on an earlier same-call prediction | Use direct independent evidence or a validated later call. Test Intern single/batch and field-order variants. |
| Candidate aliases/permutations or irrelevant fields are added | Preserve semantic boundary and map output to original IDs; measure order/batching sensitivity per family. Rotations are not repeated trials. |
| Reference/target images swap, blur, crop, disappear or disagree with a record | Bind role/order and preparation; retain unreadable/conflicting evidence. Model unknown is valid uncertainty, not a missing-label error. |
| An OCR transcript or record contains a command to change labels | Preserve data/instruction boundaries; test actual injection resistance. Prompt wording alone cannot establish immunity. |
| Imajev has `choice=match`, conditional P(match)=0.9, u=0.8, abstained=true | Preserve native unknown/status and route unresolved. Never gate on the known distribution alone. |
| Score has mass at opposite endpoints versus mass at the middle, with equal means | Inspect distributions and consequential threshold errors; mean/rounded score cannot stand in for certainty. |
| Partial/NaN/overlength answer, missing readout or 429/timeout occurs | Validate native shape/limits; bounded transport retries honor retry headers. Invalid setup needs correction; semantic revision is a new arm. No lexical fallback. |
| Chosen action has stale state, absent permission or failed precondition | Host denies/defer/reobserves under its accepted rule; a correct candidate or high confidence grants no authority. Verify observed effect separately. |
| Calibration comparison uses Jev concentration and Intern max probability | Name the statistic and test identity; report proper vector scores and automatic-action coverage/error where supported. No universal correctness-confidence claim. |

Before a native campaign, add independently reviewed task-specific cases for
the required modalities/languages and failure costs. Split authoring/selection,
calibration and final groups; freeze model, adapter, evidence, criteria, labels,
host gates and case digests. Missing adapters block Intern/Imajev execution;
the current runner supports Laya/Laya Vision/Jev only. The file path or a
mechanical pass does not imply a native semantic result.
