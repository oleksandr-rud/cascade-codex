# Visual Validation Reference

Load target-specific product, UX, brand, design, and component rules before
using these reusable heuristics.

Give each supplied governing dimension an explicit disposition. In particular,
record `brand-content-fit` against the exact brand source and visual evidence;
do not treat merely naming the brand source as a completed comparison.

- Keep the first screen useful for the named actor goal.
- Prefer organized, scannable layouts for repeated operational work when the context supports it.
- Avoid nested framing and decorative backgrounds that reduce scanability.
- Keep fixed-format controls, rows, counters, chips, and toolbars dimensionally stable.
- Do not scale type with viewport width or use negative letter spacing as a fit repair.
- Ensure labels fit and mobile layouts do not overflow horizontally.
- Use text or shape as well as color for status.

Recommended evidence matrix: 390x844, 768x1024, 1280x800, and 1440x1000,
trimmed to the product's supported devices. Cover default, loading, empty,
error, disabled, selected, long-content, and permission-denied states when
applicable.
