# Accessibility Sources

Primary sources:

- W3C WCAG 2.2: https://www.w3.org/TR/WCAG22/
- WCAG 2.2 quick reference: https://www.w3.org/WAI/WCAG22/quickref/
- WAI-ARIA Authoring Practices Guide: https://www.w3.org/WAI/ARIA/apg/
- WAI-ARIA patterns: https://www.w3.org/WAI/ARIA/apg/patterns/
- USWDS accessibility: https://designsystem.digital.gov/documentation/accessibility/
- NHS accessibility guidance: https://service-manual.nhs.uk/accessibility

Prefer manual evidence for tab and reverse-tab order, focus visibility and
obstruction, dialog entry/exit, screen-reader name/role/value, keyboard
activation, contrast, mobile target size, and reduced-motion behavior.

Severity:

- P0: prevents a critical task, creates unsafe action, or exposes sensitive data.
- P1: blocks a keyboard or assistive path for a core action or hides required state.
- P2: causes material friction, ambiguity, or partial access failure.
- P3: bounded improvement or documentation gap.
