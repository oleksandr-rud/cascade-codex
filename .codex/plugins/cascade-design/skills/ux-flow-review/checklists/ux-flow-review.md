# UX Flow Review Checklist

- [ ] Surface, actor, job, entry point, completion signal, and non-goals are bound.
- [ ] Product, scenario, journey, persona, permission, and current UI sources are identified.
- [ ] Carried state, interruption, resume, and external dependency behavior is covered.
- [ ] Entry, loading, empty, partial, error, blocked, unsaved, success, recovery, and narrow-viewport states are covered or explicitly disposed.
- [ ] Findings cite evidence and use P0-P3 severity without turning preference into fact.
- [ ] Feature UX stays separate from reusable design-system, accessibility, visual, product-definition, functional, and implementation ownership.
- [ ] Missing intent is `GAP`; unavailable required evidence is `BLOCKED`; neither is reported as pass.
- [ ] Evidence plan and next owner are explicit.
