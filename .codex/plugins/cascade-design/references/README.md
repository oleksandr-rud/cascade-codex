# Local Design reference index

Use the existing five methods as entrypoints. These references are local
knowledge and procedures, not extra skills, agents or operational permissions.
Read the relevant phase and topic rather than loading the whole corpus.

The Cascade process below reconciles the adapted sources. Accepted target
decisions and host authority govern every example. No invocation needs to fetch
an upstream skill or execute a source engine. Remote URLs in attribution and
standards notes identify provenance; the local process remains usable offline.

| Uncertain evidence, journeys or structure | [Research and information architecture](process/research-and-ia.md) |

The [vendor topic map](vendor/README.md) points to the full locally retained
procedures, research/form/configurator patterns, platform/component examples and
design datasets. [Third-party notices](THIRD-PARTY-NOTICES.md) and
`source-manifest.json` record licenses, exact upstream revisions and adaptations.
Use source examples as starting knowledge; actual product truth, stack version,
evidence and permissions decide their application.
