# Cascade AI Architect boundary

AI Architect owns capability maps, topology, behavior blueprints, framework-neutral
workflows, runtime binding contracts, role/skill briefs, prompt/evaluation briefs and
bounded improvement cycles. Prompt authoring, independent Quality evaluation, simulation
execution and host integration remain with their respective owners.

The explicitly adopted stateful profile is Analyzer/Admission/Policy Engine/Composer
version 3. Analyzer returns typed claims/action requests. Admission checks the complete
structured result against issued sources and current scope. Policy Engine orchestrates
Researcher or Composer. Each role has a Context Builder and receives a fresh permitted
view. Research observations return through new analysis. The host owns CAS, idempotency,
authoritative state, permission, budgets and publication.

The versioned contract lives in skills/design-agent-blueprint/references/analyzer-policy-composer.md,
with agent-contracts.schema.json, model-only schema closures and the executable
scripts/agent_runtime.mjs. The old writable-operation wire, binder, mutation-store
example and graph adapter are removed. Optional text projections and prefix caches are
formatting tools under the same role authority; they do not own policy or context access.

bind-agent-runtime chooses the smallest actual host binding after accepted behavior.
Graph execution is optional and requires a target adapter with equivalent boundary
evidence. No LangGraph dependency or graph adapter is shipped as a default.
run-improvement-cycle diagnoses a measured failure, prepares a scoped candidate and
compares matched independent subject evaluations. It does not require simulations for
prompt or workflow work, reset budgets or self-promote.

Schemas and controlled callback/receipt tests prove their exercised mechanical
boundaries. Provider quality, target storage/transport integration, semantic judging
and installed discovery are separately evidenced. A source reference is not a target app.
