# Workflow improvement handoff

REQUEST_RSI produces a bound improvement-request only after measured node failure.
It includes the frozen baseline plan, catalog identity, Task Envelope, control parent,
failure evidence and inherited budget. This is diagnostic input, not mutation authority.

Run one bounded cycle through run-improvement-cycle. LLM diagnosis emits one causal
hypothesis and explicit uncertainty. Prepare a scoped candidate with the owning skill,
then use the relevant independent Quality adapter with frozen failure and unseen cases.
The reducer verifies actual subject/receipt/case bytes, model/profile identity and
independent judge contexts. A regression rejects; missing evidence remains unresolved.

Preserve failed runs. Do not reset the parent budget, rewrite the baseline, self-install
or resume the old plan against a new catalog. Candidate integration requires explicit
host authority and a fresh admission/selection/plan iteration after acceptance.
