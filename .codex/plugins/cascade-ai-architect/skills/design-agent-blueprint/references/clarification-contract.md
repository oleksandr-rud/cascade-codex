# Clarification

Analyzer may request CLARIFY with a concrete question and supporting claim references.
Use it only when the answer can change the permitted action, interpretation, outcome or
material decision. Preserve unresolved claims and uncertainty. Do useful independent
work while waiting when allowed; elapsed time is not an answer or approval.

Admission validates the typed request. Policy Engine authorizes a fresh Composer call;
Composer phrases the question from current context. Authorized publication returns
WAITING_INPUT. The next answer is a new scoped observation, followed by Analyzer and
Admission. A question does not issue tools, change policy or accept a state mutation.
