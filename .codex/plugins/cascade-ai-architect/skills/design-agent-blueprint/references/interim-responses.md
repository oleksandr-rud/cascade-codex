# Interim responses

The target may publish a brief progress message while an authorized operation is pending.
Eligibility comes from actual work receipts and host policy, never a model's claimed
action or a generated state update. Define a finite frequency, expiry and output budget.

A dedicated Composer Context Builder receives only the admitted progress task, observed
work facts and permitted wording. It does not receive unrelated history or research.
The host applies the same authorization, freshness and publication gates as the main
answer. A progress message cannot imply completion, approval or a successful effect.

An optional voice renderer consumes already committed text and reports observed delivery.
It cannot alter meaning or certify that audio was heard. This target extension needs
its own declared schema and adapter tests; the core claims/actions runtime does not
pretend to implement a scheduler, voice delivery or background work.
