# Efficient Structured Tier

Use for bounded, high-volume or latency-sensitive tasks.

- Keep the prompt short, direct, and schema-first.
- Define fields, types, allowed values, ambiguity/abstention, and exact output.
- Never invent label sets or decision rules; interview material gaps.
- Use one discriminating example only when rules are insufficient.
- Repeat a critical constraint locally only where failure is plausible.
- Prefer deterministic validation and no extra commentary.
- Escalate only after representative failures remain when context, input
  quality, schema, and prompt defects are ruled out.
