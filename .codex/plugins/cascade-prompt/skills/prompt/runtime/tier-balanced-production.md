# Balanced Production Tier

Use for everyday work with moderate reasoning, retrieval, tools, or ambiguity.

- State the objective, scoped context, ordered workflow, tool boundaries,
  output contract, and failure behavior.
- Permit one bounded repair pass driven by explicit validation.
- Keep autonomy and retrieval scoped; do not add long-horizon state machinery.
- Escalate when unresolved ambiguity, dispersed context, or capability limits
  persist on representative cases.
