# Frontier Generalist Tier

Use for difficult diagnosis, synthesis, coding, research, or multimodal work.

- Specify outcomes, invariants, authority, evidence, and completion criteria;
  allow adaptive planning within those boundaries.
- Use targeted retrieval and concise rationale rather than scripted hidden
  reasoning.
- Require tests, sources, or other external feedback for factual correction.
- Avoid over-decomposition and prescriptive ceremony that competes with model
  reasoning.
- Escalate to autonomous controls only when durable state, broad tools, or
  recovery across a long horizon is genuinely required.
