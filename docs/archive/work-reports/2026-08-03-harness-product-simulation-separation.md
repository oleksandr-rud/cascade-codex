# Harness And Product Simulation Separation Completion

Date: 2026-08-03
Lane: `W-027`
Status: `COMPLETE`
Terminal receipt: `W027-CLOSEOUT-20260803-A1`

## Outcome

Cascade simulation definitions now have two explicit authority roots. Harness
fixtures live under `evals/simulations/harness/`; target-product simulations
live under `evals/simulations/product/`. Each manifest declares
`simulation_scope`, the executable resolver binds that field to its physical
root and co-located definitions, and the generated campaign catalog exposes
the resolved scope.

The current correctness fixture moved to the harness root. The target
initializer now defaults to the product root while retaining conservative
framework calibration and `NOT_RUN` target/release boundaries. Harness-scoped
simulations cannot bind non-framework calibration. Product scope states
intended authority only and does not supply target evidence.

`evals/harness/` remains a separate system: it is the Cascade skill/agent
scenario and trace evaluation corpus, not a simulation-definition root.

## Bugs And Staleness Repaired

- Generic simulation paths allowed framework and target authority to be
  inferred from titles and tiers. Scope is now explicit in schema, runtime,
  paths, catalogs, configs, docs, and defaults.
- Campaign-only validation missed unreferenced manifests. The repository
  validator now scans every scoped manifest, rejects generic top-level
  directories, and rejects duplicate simulation IDs across scopes.
- Persona population preview assumed the old generic path. It now resolves one
  exact ID across both roots and fails closed on zero or multiple matches.
- `browser_simulations: evals/simulations` was an unused ambiguous default.
  Harness configs now expose `harness_simulations` and `product_simulations`,
  and the target config schema requires their canonical roots.
- The P-999 persona/derivation/population provenance chain was rebound after
  its live derivation path changed; stale digests failed closed during the
  first test loop as intended.
- Empty generic-root shells for the migrated correctness fixture and historical
  `target-bootstrap` preview were verified empty and removed.
