# Product Simulations

Target-product simulations live in one folder per simulation ID. Use
`bun scripts/cascade.ts simulation init <id> --owner-lane W-NNN --dry-run` to
preview the default product-scoped starter before writing it.

A product-scoped starter is authored framework scaffolding until target
adapters, evidence, reference data, calibration, execution, evaluation, and
cleanup gates prove more. Scope alone never upgrades a claim.

Current scaffold state: no target-product simulation has been authored or run.
Do not copy the harness fixture here and relabel it. Seed a real product
simulation from a reviewed non-fixture persona and governed evidence, then keep
persona-derived coverage separate from estimated-prevalence authority.
