# Primary diagram references

References checked 2026-10-10. Historical manuals describe notation, not current
mandatory regulatory requirements. Detailed package examples and implementation
mappings are original adaptations; we do not distribute copies of source manuals.

| Method | Primary reference | Package use |
|---|---|---|
| IDEF0 | [KBSI](https://www.idef.com/idefo-function_modeling_method/); [FIPS 183](https://nvlpubs.nist.gov/nistpubs/Legacy/FIPS/fipspub183.pdf) | Functional interfaces and decomposition |
| IDEF1 | [Information modeling manual](https://www.idef.com/wp-content/uploads/2022/08/IDEF1MR.pdf) | Information requirements |
| IDEF1X | [KBSI](https://www.idef.com/idef1x-data-modeling-method/); [FIPS 184](https://nvlpubs.nist.gov/nistpubs/Legacy/FIPS/fipspub184.pdf) | Relational logical design |
| IDEF3 | [KBSI](https://www.idef.com/idef3-process-description-capture-method/); [manual collection](https://www.idef.com/downloads/) | Process and object-state viewpoints |
| IDEF4 | [KBSI](https://www.idef.com/idef4-object-oriented-design-method/) | Typed method and dependency contracts |
| IDEF5 | [KBSI](https://www.idef.com/idef5-ontology-description-capture-method/) | Definitions and concept relations |
| IDEF6/8/9/14 | [IICE compendium](https://www.idef.com/wp-content/uploads/2016/02/compendium.pdf) | Rationale, interaction, rules and networks |
| IDEF2; family coverage | [Family manual](https://www.idef.com/wp-content/uploads/2022/08/IDEF1MR.pdf) | Resource simulation when needed |
| C4 | [Official diagrams](https://c4model.com/diagrams) | Context/container/component views |
| Mermaid | [Flowchart](https://mermaid.js.org/syntax/flowchart.html), [sequence](https://mermaid.js.org/syntax/sequenceDiagram.html), [state](https://mermaid.js.org/syntax/stateDiagram.html), [ER](https://mermaid.js.org/syntax/entityRelationshipDiagram.html), [class](https://mermaid.js.org/syntax/classDiagram.html) | Editable practical views |
| BPMN | [OMG 2.0.2](https://www.omg.org/spec/BPMN/2.0.2/) | Optional formal company/process modeling |

The historical compendium reports partial development of IDEF6/8/9/14 at that
time. Do not assume equal method completeness or infer present status from its
age. IDEF7 and IDEF10–13 appear as additional/planned family directions, with
some naming/numbering differences across the historical materials. This package
does not claim full implementations of those methods. Its policies use the
specific, documented viewpoints named above.
